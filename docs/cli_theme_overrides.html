CLI options and themes

The theme loads first (load_run_theme in cli/config_assembly.py), then every explicitly given CLI option is applied on top, so a CLI option always beats the theme. There is no second theme pass and no re-assertion step.

Options in _CLI_CONFIG_OVERRIDES target either a CalendarConfig field or a theme path (theme:<dotted.path>, written with config/theme_paths.set_path). The theme-path overrides are listed below; tests/test_cli_theme_precedence.py guards the behaviour.

OptionTargetKind
--mini-columnsmini_columnsvalue
--mini-rowsmini_rowsvalue
--details-mdtheme:details.markdown.enableenable
--no-details-mdtheme:details.markdown.enabledisable
--iconstheme:details.icons.enableenable
--no-iconstheme:details.icons.enabledisable
--csvtheme:details.csv.enableenable
--no-csvtheme:details.csv.enabledisable
--candybar-row-heighttheme:candybar.row_heightvalue
--candybar-cell-widththeme:candybar.cell_widthvalue
--candybar-max-rows-per-pagetheme:candybar.max_rows_per_pagevalue
--fiscal-year-offsettheme:fiscal.year_offsetvalue

Decoration (timescale, today line, palettes, fonts, holidays, patterns) has no CLI options; it is set only by the theme. See the User Guide's Theme System chapter.
