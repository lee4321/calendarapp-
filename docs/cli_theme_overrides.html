CLI Options That Override Theme Values

EventCalendar v9 — full review of visualizer CLI options vs. theme-settable config fields.
Generated 2026-07-09 from cli/args.py, cli/config_assembly.py, config/theme_engine.py, and ecalendar.run(); precedence verified empirically by capturing the final CalendarConfig handed to each visualizer.

How precedence actually works. For calendar views, run() applies CLI arguments first, then applies the theme twice (before and after setfontsizes()). After the second theme pass, _reapply_post_theme_cli_overrides() re-asserts only a small hand-picked set of CLI flags. Consequence: CLI wins only for that re-asserted set; for every other overlapping option the theme wins whenever the loaded theme defines the same key — the explicit CLI value is silently discarded. This contradicts the theme engine's documented contract (theme_engine.py line 11: “CLI arguments always override theme values.”). Rows marked ✓ were verified end-to-end with a conflicting theme + CLI value.

The CLI flag cannot disable theme margins. Verified ✓.

Excel views: excelheader and excelblockplan apply the theme once, after their CLI assignments; none of their CLI options (--weekends, --weekend-days, --country, content filters) map to theme-settable fields, so they have no CLI/theme overlaps.

Also: --monthnames writes include_month_number = False, but include_month_number has no readers anywhere — it is a dead config field. And every option in Section 2 becomes a conditional no-op whenever the loaded theme defines the same key.

Appendix B  Spurious “will be ignored” warnings (options that actually work)

The _svg_layout_checks table in ecalendar.run() compares option names against visualizer.supported_options, but several names appear in no supported list (or the work happens in the shared BaseSVGRenderer regardless), so the warning is wrong:

  • --headerleft / --headercenter / --headerright / --footerleft / --footercenter / --footerright — warned on every view, yet render on every view when --header/--footer is enabled (verified ✓).
  • --watermark-rotation-angle — warned on every view; applied by BaseSVGRenderer._render_text_watermark() on every view.
  • --shrink — warned on weekly, blockplan, compactplan; the viewBox recomputation runs in BaseSVGRenderer for all views regardless (verified ✓ on weekly).

Review method: static trace of argparse option → CalendarConfig field → renderer/layout reads (including getattr-string access), cross-referenced with THEME_TO_CONFIG_MAP, _apply_pit_blocks(), _apply_layout_overrides() and _reapply_post_theme_cli_overrides(); precedence confirmed by running the real ecalendar.run() pipeline with a conflicting theme and capturing the final config (probe script + conflict theme preserved in session scratchpad).
